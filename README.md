# 千夏快跑

校园跑 / 轨迹模拟工具（Android）。

## 下载

- 下载页：https://47.108.239.171/download/
- 直链：https://47.108.239.171/download/chinatsu-toolbox-1.3.4.apk

## 安装

1. 下载 APK
2. 允许「安装未知来源应用」
3. 覆盖安装即可，数据与授权保留

## 更新

App 内「我的 → 检查更新」读取官方更新通道，会提示新版本号与更新日志。
